# WHERE Clause in SQL

This file contains structured SQL practice questions focused on the `WHERE` clause.
It is designed for beginners as well as interview preparation for Data Analyst / Data Scientist roles.

---

## 📌 Topics Covered

- Basic WHERE conditions
- AND / OR operators
- Comparison operators (`=`, `!=`, `>`, `<`, `BETWEEN`)
- `IN` and `NOT IN`
- Pattern matching using `LIKE`
- Handling `NULL` values
- WHERE clause with subqueries
- Real-world business use cases
